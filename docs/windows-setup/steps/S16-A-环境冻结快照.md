# S16-A：环境冻结快照

本步骤保存可复现信息，不修改源码、不提交Git，也不删除任何文件。

## 1. 关闭本轮GUI

确认导出已完成后，用窗口右上角关闭On-the-fly SfM。等待数秒，在PowerShell执行：

```powershell
Get-Process -Name UI -ErrorAction SilentlyContinue
```

无输出表示本轮UI进程已经结束。若仍显示UI进程，先等待并正常关闭窗口，不用`Stop-Process`强制结束。

## 2. 生成冻结快照

由于本机Windows PowerShell默认阻止脚本，使用仅对这个子进程生效的ExecutionPolicy Bypass，不修改系统策略：

```powershell
& powershell.exe -NoProfile -ExecutionPolicy Bypass -File `
  '<原工作记录目录>\feedback_local_setup\freeze_windows_environment.ps1'

$taskFreezeExit = $LASTEXITCODE
$taskFreezeExit
```

脚本目标目录固定为E:\sfm\setup\S16-freeze-20261014，重复运行会更新同名记录，但不会清理目录或源码。它会保存：

* requirements-tested.txt和environment-tested.yml；
* vcpkg-installed.txt及主要工具版本；
* Git提交、分支、远程、状态、diff统计和可应用的文本补丁；
* settings.ini、本机props、glog兼容头、vcpkg manifest/triplet/overlay；
* 四个模型及本轮导出文件的大小和SHA256；
* S16-freeze-report.json。

通过标准：输出中必须同时出现`[OK] vcpkg entries: 数量`、`Result: PASS`，且`$taskFreezeExit`为0。只看到vcpkg的`No packages are installed`即使退出0也不算通过。返回完整输出；之后再做S16-B Git本地提交与最终复现清单。
