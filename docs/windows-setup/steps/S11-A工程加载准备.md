## 1. 关闭当前VS窗口，修正两个CUDA工程的导入

仓库当前SIFTGPU与Scene导入CUDA11.8.props/targets，本机安装12.2。先备份这两个工程，再只替换四处导入文件名：

```powershell
$taskCudaProjects = @(
    'E:\sfm\OntheflySfMFeedback\thirdparty\SIFTGPU\SIFTGPU.vcxproj',
    'E:\sfm\OntheflySfMFeedback\src\Scene\Scene.vcxproj'
)
$taskProjectBackup = 'E:\sfm\setup\S11-original-projects'
New-Item -ItemType Directory -Force -Path $taskProjectBackup | Out-Null
foreach ($taskProject in $taskCudaProjects) {
    $taskBackupFile = Join-Path $taskProjectBackup (Split-Path -Leaf $taskProject)
    if (-not (Test-Path -LiteralPath $taskBackupFile)) {
        Copy-Item -LiteralPath $taskProject -Destination $taskBackupFile
    }
    $taskProjectText = [IO.File]::ReadAllText($taskProject)
    $taskProjectText = $taskProjectText.Replace('CUDA 11.8.props','CUDA 12.2.props').Replace('CUDA 11.8.targets','CUDA 12.2.targets')
    [IO.File]::WriteAllText($taskProject, $taskProjectText, [Text.UTF8Encoding]::new($false))
}
```

这只改工程的CUDA构建规则导入，源码算法和其余历史路径本阶段保留，后续B再配置。

检验：

