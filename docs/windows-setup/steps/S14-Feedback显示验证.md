## S14-A：网格（已通过）

先确保Show Quality与Show Guide Path未勾选，只勾选Show Mesh。等待界面刷新后，在Model Viewer中旋转或缩放观察建筑区域。

通过标准：与关闭Show Mesh相比，场景出现由三角面或网格边构成的表面结构，并且程序保持可操作。红色相机图标不属于网格证据。记录开关前后差异并保存截图。
