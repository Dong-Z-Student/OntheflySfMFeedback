## 三、每个单元的学习记录模板

每读完一个单元，记录以下五项，避免只浏览代码：

1. 入口函数与触发条件。
2. 主要输入、输出及拥有这些数据的类。
3. 至少一条实际运行值，例如imageID、匹配数量或选中视点数。

5. 仍不理解的问题，以及自己的暂定解释。

建议把断点放在业务函数入口，先使用条件断点或只跑少量图片。trial02全量运行适合最终核对，不适合每次单步。源码学习中的实验改动另建分支，例如`study/s17-notes`；已验证的`local/windows-setup`保持不变。
