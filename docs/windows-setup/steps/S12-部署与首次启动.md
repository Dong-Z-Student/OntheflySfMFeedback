## B. 首次启动（A验收后执行）

以下环境变量只作用于当前终端及其子进程，不修改系统设置。PythonHome由INI和C++ PyConfig设置；清除当前终端可能遗留的PYTHONHOME/PYTHONPATH，使用部署目录的Qt插件。

```powershell
$taskRuntimeDirs = @(
    'E:\sfm\runtime\Release',
    'E:\sfm\envs\feedback310',
    'E:\sfm\envs\feedback310\DLLs',
    'E:\sfm\envs\feedback310\Library\bin',
    'E:\sfm\OntheflySfMFeedback\vcpkg_installed\x64-windows\bin',
    'D:\CUDA\v12.2\bin'
)
$env:PATH = ($taskRuntimeDirs -join ';') + ';' + $env:PATH
$env:CUDA_PATH = 'D:\CUDA\v12.2'
Remove-Item Env:\PYTHONHOME,Env:\PYTHONPATH,Env:\QT_PLUGIN_PATH -ErrorAction SilentlyContinue
$env:QT_QPA_PLATFORM_PLUGIN_PATH = 'E:\sfm\runtime\Release\platforms'
$env:GLOG_logtostderr = '1'
Set-Location -LiteralPath 'E:\sfm\runtime\Release'
$taskUiProcess = Start-Process -FilePath 'E:\sfm\runtime\Release\UI.exe' -WorkingDirectory 'E:\sfm\runtime\Release' -RedirectStandardOutput 'E:\sfm\setup\S12B-UI-stdout.log' -RedirectStandardError 'E:\sfm\setup\S12B-UI-stderr.log' -PassThru
Start-Sleep -Seconds 10
$taskUiProcess.Refresh()
$taskUiProcess | Select-Object Id,HasExited
if ($taskUiProcess.HasExited) { $taskUiProcess.ExitCode }
Get-Content -LiteralPath 'E:\sfm\setup\S12B-UI-stderr.log' -Tail 50
```

启动前确保上一份UI已关闭，避免重复启动。助手本轮核查时无UI进程。观察主窗口及Log区域，模型后台加载可能需要超过10秒；只有进程还活着不算通过。HasExited=False表示进程仍运行；只有HasExited=True时才读取ExitCode。加载完成后可重新运行Get-Content读取新增日志。

通过标准：GUI稳定出现，无DLL/Qt插件错误；日志有Python3.10和“The global extractor has been successfully loaded!”。仅窗口出现而模型报错时，B尚未通过。记录stderr/stdout以及GUI日志；不开始照片输入，先完成启动验收。

若失败：返回完整报错文本、两个启动日志末尾及退出码（若已退出）。GlobalFeatureExtractor找不到时先核查内嵌解释器sys.path；单独Python在S10通过不意味着C++内嵌路径已通过。保留当前证据后再定位修复，不先重装全部环境。
